# F0021 — Communication Hub & Activity Capture

**Status:** In Progress
**Priority:** High
**Phase:** CRM Release MVP

## Overview

Capture notes, calls, meetings, and follow-up history so communication becomes part of the CRM record instead of living only in inboxes. Surfaces a Communications feed tab on broker, account, submission, policy, and renewal detail pages.
